#### PASO 4: Guidelines Específicas (Priority Order)

**Priority 1 - CRITICAL:**
- [ ] Contraste 4.5:1 en todos los textos
- [ ] Etiquetas alt en imágenes/íconos
- [ ] Navegación por teclado completa
- [ ] Aria-labels en botones críticos

**Priority 2 - HIGH:**
- [ ] Tamaño mínimo 44×44px en elementos táctiles
- [ ] Espaciado 8px+ entre elementos interactivos
- [ ] Loading feedback visible (no estados instantáneos 0ms)
- [ ] WebP/AVIF para imágenes
- [ ] Lazy loading de streams

**Priority 3 - MEDIUM:**
- [ ] Tipografía base 16px, line-height 1.5
- [ ] Tokens de color semánticos (no raw hex)
- [ ] Animaciones context-aware con GSAP
- [ ] Errores cerca del campo, no solo arriba
- [ ] Navegación predecible: back behavior

**Priority 4 - LOW:**
- [ ] Leyendas de charts con colores accesibles
- [ ] Evitar depender solo del color para Convey meaning
